# پیام‌های خطا و راه رفع

خطاهای عملیات داخل همان فرم نمایش داده می‌شوند؛ پیام پشت پنجرهٔ تار نمی‌ماند. عنوان، توضیح علت، راه رفع و کد خطا جدا هستند. ورودی‌های فرم پس از خطا پاک نمی‌شوند. دکمهٔ ضربدر فقط پیام را می‌بندد.

| کد | علت | اقدام |
|---|---|---|
| login_required / login_failed | ورود انجام نشده، منقضی شده یا اطلاعات ورود نادرست است | دوباره با حساب ثنایی وارد شوید؛ رمز و کد دومرحله‌ای را بررسی کنید. |
| csrf_expired | اعتبار امنیتی درخواست تمام شده است | اطلاعات فرم را نگه دارید و صفحه و ورود را تازه کنید. |
| origin_mismatch / host_not_allowed | دامنه، IP یا پورت درخواست با آدرس مجاز پنل متفاوت است | آدرس ثبت‌شدهٔ افزونه را باز کنید. |
| rate_limited | تلاش‌های زیاد در زمان کوتاه | پنج دقیقه صبر کنید. |
| license_required | مجوز همین محصول نیازمند بررسی است | تب مستقل «لایسنس» را باز کنید. |
| port_unavailable | پورت مسیر جدید آزاد یا در محدودهٔ مجاز نیست | پورت آزاد بین ۱۰۲۴ و ۶۰۹۹۹ انتخاب کنید. |
| host_address_invalid | مقدار Host به‌صورت لینک، مسیر وب، IP یا پورت نامعتبر وارد شده | فقط دامنه/IP و پورت اختیاری بنویسید؛ برای نمونه example.com:443. |
| proxy_invalid | قالب یا اطلاعات خروجی SOCKS معتبر نیست | دامنه، پورت و اطلاعات ورود خروجی را بررسی کنید. |
| inbound_required | اینباند مرتبط انتخاب نشده یا مناسب نیست | برای کشور، اینباند TCP سازگار؛ برای Host، اینباندهای مرتبط را انتخاب کنید. |
| engine_missing | موتور خروجی نصب نشده است | وضعیت موتور را در تنظیمات بررسی کنید یا SOCKS خودتان را انتخاب کنید. |
| metadata_stale | فهرست اینباندها همگام نشده است | اطلاعات را تازه کنید؛ تا رفع مشکل ضریب تغییر نمی‌کند. |
| stale_revision | تنظیمات از زمان بازکردن فرم، توسط ویرایش دیگری تغییر کرده | فهرست را تازه کنید و نسخهٔ جدید مورد را باز کنید. |
| operation_pending / write_unconfirmed | عملیات نیمه‌تمام است یا ثبت آن قطعی تأیید نشده | در میزبان‌ها یا اتصال و بازیابی، وضعیت عملیات را بررسی کنید؛ ثبت را پیاپی تکرار نکنید. |
| request_timeout / upstream_timeout | پاسخ مرورگر یا سرویس دیرتر از مهلت رسید | احتمال انجام درخواست وجود دارد؛ پیش از ارسال مجدد وضعیت را بخوانید. |
| network_error / service_unavailable / panel_unavailable | ارتباط مرورگر، سرویس مدیریت یا ثنایی برقرار نشده | اینترنت، آدرس و پورت و فعال‌بودن سرویس را بررسی کنید. |
| tls_error | گواهی HTTPS سرویس قابل تأیید نیست | دامنه، تاریخ و زنجیرهٔ گواهی را اصلاح کنید؛ اعتبارسنجی را غیرفعال نکنید. |
| invalid_response | پاسخ خالی، HTML یا قالبی ناسازگار با API دریافت شده | سرویس مدیریت و واسطهٔ HTTPS را بررسی کنید. |
| internal_error | خطای داخلی که علتش از پاسخ عمومی مشخص نیست | شناسهٔ خطا را برای بررسی گزارش سرور نگه دارید؛ علت نامعلوم حدس زده نمی‌شود. |

کلید لایسنس، توکن و رمزهای داخل آدرس خروجی در متن خطا مخفی می‌شوند. خطای پس‌زمینه، پیام اصلی فرم را جایگزین نمی‌کند. خطاهای ثبت خودکار دوباره ارسال نمی‌شوند تا تغییر تکراری اتفاق نیفتد.
